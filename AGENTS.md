# User publication boundary

- Never modify or publish to `kolygri.github.io`, including project subpaths, without asking the user and receiving explicit approval for that specific change.
- Never modify `kolygri/kolygri.github.io`, its Pages settings, deployments, custom domains, or DNS without that approval.
- Keep GitHub Pages disabled for this reading-site snapshot. The library uses a separate Sites host.
- Read-only verification is allowed. Preserve unrelated user changes.
